# AI CCTV YOLO Project

This project uses YOLOv8 and deep learning to monitor CCTV feeds for security threats, including fire detection, crowd management, and crime/anomaly detection.

## 🚀 Features
- **Fire Detection:** Real-time monitoring for fire using YOLOv8.
- **Crime Detection:** Identification of suspicious activities (e.g., weapons/pointing guns).
- **Crowd Detection:** Monitoring crowd density and movement.
- **Dashboard:** A central interface to view all detections.

## 🛠️ Built With
- **Python**
- **YOLOv8 (Ultralytics)**
- **TensorFlow/Keras** (for crime classification)
- **OpenCV** (for video processing)
